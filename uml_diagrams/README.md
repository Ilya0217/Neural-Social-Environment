## 🚀 Быстрый старт

### Визуализация упрощённой версии:

1. **Онлайн (самый простой способ)**:
   - Откройте: http://www.plantuml.com/plantuml/uml/
   - Скопируйте содержимое `agent_dialogue_sim_final.puml`
   - Вставьте в редактор
   - Нажмите "Submit"
   - Сохраните изображение (PNG/SVG)

2. **VS Code**:
   - Установите расширение "PlantUML" (jebbs.plantuml)
   - Откройте `agent_dialogue_sim_final.puml`
   - Нажмите `Alt+D` для предпросмотра
   - Экспортируйте в PNG: `Ctrl+Shift+P` → "PlantUML: Export Current Diagram"

3. **CLI** (требует установки PlantUML):
   ```bash
   plantuml agent_dialogue_sim_final.puml
   ```

## 📐 Что включено в упрощённую версию

### Ядро системы:
- **Agent** - виртуальный участник диалога
- **DialogueManager** - центральный оркестратор
- **AgentTurn** - структурированный ответ

### Система валидации:
- **BaseValidator** - базовый класс (Strategy Pattern)
- **ValidationPipeline** - оркестратор валидации
- 4 типа валидаторов (объединены для компактности)

### Аналитика:
- **MetricsCalculator** - расчёт метрик
- **ScientificAnalyzer** - научный анализ

### Интерфейсы:
- **WebApp** - веб-интерфейс
- **IOLogger** - логирование

## 💡 Советы для научной работы

1. **Размер**: Упрощённая версия оптимизирована для формата A4
2. **Качество**: Используйте SVG для векторного качества
3. **Разрешение**: Для печати используйте минимум 300 DPI
4. **Подписи**: Все связи подписаны на русском языке
