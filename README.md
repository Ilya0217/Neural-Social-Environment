# 🎭 Agent Dialogue Simulator

Программный комплекс для моделирования многоагентных диалогов с использованием LLM (Large Language Models).  
Система имитирует общение агентов с разными ролями и характерами, фиксирует **тональность**, **эмоции** и **адресацию** реплик, а также визуализирует их в виде графа.

---

## 📌 Возможности
- 📚 **Многоагентные диалоги** — агенты с разными ролями (Исследователь, Критик, Медиатор, Пользователь).
- 😀 **Аффективный анализ** — каждая реплика помечается тоном (positive / neutral / negative) и эмоцией.
- 📊 **Визуализация** — строится граф взаимодействий:  
  - узлы — агенты (обводка = последняя эмоция, размер = число реплик),  
  - рёбра — отдельные реплики (стрелка от говорящего к адресату, цвет = тональность).
- 📝 **Логирование** — диалоги сохраняются в:
  - `logs/dialog.jsonl` (структурированный лог),  
  - `logs/dialog.md` (удобочитаемый Markdown-журнал).
- 🌐 **Интерактивность** — четвёртый агент — это **вы**, пользователь, отвечаете, когда к вам обращаются.
