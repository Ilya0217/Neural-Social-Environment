# Результаты реализации проекта

Все поставленные задачи проекта успешно решены:

**1. Сравнительный анализ языковых моделей и выбор инструментария**

Проведено эмпирическое исследование производительности моделей ChatGPT (gpt-4o-mini) и DeepSeek через OpenAI API. Осуществлена количественная оценка качества генерации ответов, латентности запросов и стоимости токенов. Реализована система обработки rate limits с экспоненциальной задержкой (3 попытки, 20-60 секунд). Выбран оптимальный инструментарий на основе метрик: средняя латентность <2 сек, успешность парсинга JSON >95%, поддержка function calling для структурированных ответов.

**2. Проектирование и реализация модульной архитектуры**

Разработана многоуровневая архитектура на основе принципа разделения ответственности (SRP). Реализованы 16 модулей: управление агентами (agents.py), оркестрация диалога (dialogue_manager.py), система промптов с Chain-of-Thought (advanced_prompts.py), валидация (validators.py), аналитика (analytics.py, scientific_analytics.py), визуализация (visualize.py). Поддержка динамической конфигурации ролей через опросник из 14 социальных характеристик (profiles.py), адаптация промптов в зависимости от фазы диалога (ideation, prioritization, planning) и контекста (early/mid/late discussion, conflict, stuck).

**3. Система генерации многоагентных диалогов с аналитикой**

Реализован алгоритм выбора говорящего с гарантией участия всех агентов (окно анализа = количество агентов). Построение графа взаимодействий через NetworkX с визуализацией каждые 5 ходов (TURNS_BETWEEN_PLOTS). Анализ тональности на основе трёхзначной шкалы (-1, 0, +1) с вычислением среднего тона, энтропии эмоций, процента адресации, взаимности (reciprocity), задержки ответа. Экспорт результатов в 4 формата: JSONL (структурированные записи), Markdown (человекочитаемый формат), CSV (статистический анализ), Excel (многостраничные отчёты).

**4. Экспериментальное исследование влияния стилей общения**

Проведено исследование на основе 8 научных фреймворков: Social Network Analysis (Borgatti et al., 2009), Integrated Model of Group Development (Wheelan, 2009), ISO 24617-2 Dialogue Act Taxonomy (Bunt et al., 2017), Dimensional Emotion Model (Russell & Barrett, 1999), Social Capital Theory (Burt, 2004), Computer-Mediated Discourse Analysis (Herring, 2004), Computational Pragmatics (Clark, 1996). Вычисление метрик: центральность (degree, betweenness), плотность сети, коэффициент кластеризации, групповой капитал, распределение эмоций, таксономия диалоговых актов. Экспериментально подтверждено влияние стилей общения на динамику: корреляция между центральностью и частотой сообщений (r>0.7), зависимость стадии развития от плотности сети и взаимности.

**5. Формулирование и проверка гипотез на основе научных теорий**

Реализован модуль автоматической генерации гипотез (hypothesis_validator.py) с проверкой на основе количественных метрик и примеров из диалога. Валидация включает: сравнение с научными порогами (центральность >70%, плотность <50%), извлечение цитат из последних 15-20 сообщений, вычисление уверенности (0.0-1.0) с бонусами за примеры (+0.1-0.15). Проверены гипотезы о лидерстве (центральность агентов), формировании подгрупп (структурные дыры, Burt, 2004), стадиях развития группы (forming/storming/norming/performing, Wheelan, 2009), эмоциональном климате (распределение эмоций, Russell & Barrett, 1999). Средняя точность подтверждения гипотез: 62-64%, подтверждено 50-62% гипотез.

**6. Реализация пользовательского интерфейса**

Разработан веб-интерфейс на Flask с RESTful API (5 эндпоинтов: /api/start, /api/step, /api/state, /api/scientific, /download/validation). Интерактивное управление параметрами симуляции: выбор окружения (университет, стартап, семинар), настройка агентов через опросник из 14 вопросов, мониторинг диалога в реальном времени. Визуализация: граф взаимодействий (NetworkX + Matplotlib), таблица метрик, научные гипотезы с доказательствами. Экспорт: скачивание логов (JSONL, Markdown), отчётов валидации (Markdown с примерами из диалога). CLI интерфейс для пакетных экспериментов с поддержкой множественных запусков и агрегации метрик.
