# Предрегистрация исследования (Preregistration)

**Тема:** Разработка комплекса средств для использования больших языковых моделей в социальной сфере

**Объект исследования:** Многоагентная диалоговая система на базе больших языковых моделей (LLM), имитирующая социальное взаимодействие в малых группах.

**Предмет исследования:** Способность LLM-агентов воспроизводить статистически значимые социально-психологические закономерности, известные из эмпирических исследований реальных групп.

**Дата фиксации гипотез:** до начала экспериментов.
**Принцип:** гипотезы фиксируются ДО сбора и анализа данных. Любое отклонение от протокола фиксируется в журнале изменений в конце документа с указанием причины.

---

## 1. Исследовательский вопрос

**Главный вопрос (RQ-main):**
> Способна ли многоагентная система на базе LLM, при использовании персонологической параметризации (Big Five) и многоуровневой валидации, воспроизводить статистически значимые социально-психологические закономерности малых групп с эффектами размера ≥ medium (Cohen's d ≥ 0.5 / η² ≥ 0.06)?

**Подвопросы:**

- **RQ-1:** Влияют ли параметры Big Five (заданные через системный промпт) на наблюдаемое лингво-поведенческое профилирование агента (длина реплики, доля task-ориентированных актов) на статистически значимом уровне?
- **RQ-2:** Воспроизводит ли многоагентная система временную последовательность стадий развития группы по Wheelan (forming → storming → norming → performing) на уровне, статистически отличимом от случайной марковской цепи?
- **RQ-3:** Снижает ли многоуровневая валидация (грамматика → логика → этика) долю реплик, нарушающих моральные принципы Beauchamp & Childress, статистически значимо по сравнению с базовой конфигурацией без валидации?
- **RQ-4:** Улучшает ли Chain-of-Thought-промптинг качество диалога (по операционализированным метрикам) по сравнению с базовым промптом?
- **RQ-5:** Соответствует ли распределение коэффициента Джини турн-тейкинга в LLM-симуляции распределению, наблюдаемому в корпусах реальных малых групп?

## 3. Гипотезы

Все гипотезы формулируются в форме нулевой (H₀) и альтернативной (H₁) с указанием статистического критерия, уровня значимости α, минимального размера эффекта и решающего правила.

Общие соглашения:
- Уровень значимости по умолчанию: **α = 0.05**.
- Поправка на множественные сравнения: **Holm–Bonferroni** при семействе из K тестов.
- Мощность теста при планировании: **1 − β = 0.80**.
- Минимально значимый эффект: **medium** по классификации Cohen (d = 0.5; η² = 0.06; ρ = 0.3; w = 0.3).
- Все стат. тесты выполняются в `scipy.stats` / `statsmodels`. Конкретные функции указаны.

### H1. Влияние экстраверсии на длину реплики (RQ-1)

**Теоретическое обоснование:** Mehl et al. (2006) показали, что экстраверты в реальных диалогах продуцируют больше речи и более длинные реплики.

**Операционализация:**
- Независимая переменная X — уровень экстраверсии агента, заданный через `BigFiveProfile.extraversion`. Категориально: **low** (≤ 0.3), **mid** ∈ (0.3, 0.7), **high** (≥ 0.7).
- Зависимая переменная Y — средняя длина реплики агента в словах за диалог.
- Контрольные переменные: остальные четыре черты OCEAN зафиксированы на 0.5; роль агента = "explorer"; модель LLM, температура, длина диалога фиксированы.

**Гипотезы:**
- **H₀:** μ_low = μ_mid = μ_high.
- **H₁:** ∃ i, j : μ_i ≠ μ_j.

**Статистический критерий:** однофакторный ANOVA (`scipy.stats.f_oneway`); пост-хок — Tukey HSD при отвержении H₀.

**Решающее правило:** H₀ отвергается, если **p < 0.05 И η² ≥ 0.06**. Иначе — нет оснований отвергнуть H₀.

**План выборки:** N = 60 диалогов (по 20 на уровень экстраверсии); каждый диалог = 20 ходов; единица анализа = один агент в одном диалоге; фиксированные random seeds {1..60}.

**Ожидаемый результат:** при подтверждении H₁ — high-extraversion агенты продуцируют статистически значимо более длинные реплики.

---

### H3. Воспроизведение стадий развития группы (RQ-2)

**Теоретическое обоснование:** Wheelan (2009) — последовательность стадий forming → storming → norming → performing наблюдается в реальных малых группах с предсказуемой структурой переходов; стадии диагностируются по соотношению категорий диалоговых актов (ISO 24617-2): доля socio-emotional vs task, доля negative socio (storming), доля agreements (norming).

**Операционализация:**
- Каждый диалог разбивается на скользящие окна W = 10 ходов (шаг 5 ходов).
- Для каждого окна вычисляется вектор признаков (доли диалоговых актов) и определяется стадия sₖ ∈ {forming=1, storming=2, norming=3, performing=4} классификатором, обученным на правилах из `scientific_analytics.py`.
- Получаем последовательность (s₁, s₂, ..., s_K) для каждого диалога.
- Строится матрица переходов P = [p_ij]₄ₓ₄.

**Гипотезы:**
- **H₀:** последовательность стадий случайна — наблюдаемая матрица переходов P_obs неотличима от равномерной матрицы P_uniform = (1/4)·𝟙 (вероятность каждого перехода равна 0.25).
- **H₁:** P_obs ≠ P_uniform.

**Статистический критерий:** χ²-тест согласия (`scipy.stats.chisquare`) для матрицы переходов; α = 0.01 (более строгий из-за чувствительности теста к размеру выборки).

**Дополнительный тест монотонности:** тест тренда Кокса–Стюарта (Cox–Stuart) на медианном индексе стадии в первых vs последних окнах диалога: ожидаем рост индекса (stadium → performing).

**Решающее правило:** H₀ отвергается, если **χ²-тест: p < 0.01 И w (Cohen's w) ≥ 0.3** И **тест Кокса–Стюарта подтверждает положительный тренд (p < 0.05)**.

**План выборки:** N = 30 независимых диалогов; длина каждого = 40 ходов; роли = {explorer, critic, facilitator}; OCEAN рандомизированы с фиксированным seed.

**Ожидаемый результат:** при подтверждении H₁ — наблюдается структурированный переход через стадии с тенденцией к performing.

### H5. Эффективность многоуровневой валидации (RQ-3)

**Теоретическое обоснование:** Beauchamp & Childress (2019) — четыре принципа (fairness, autonomy, inclusivity, non-maleficence). LLM без валидации генерирует токсичные/несправедливые/принуждающие реплики с ненулевой частотой; валидационный конвейер должен снижать эту частоту.

**Операционализация:**
- Bernoulli-исход для каждой реплики: y ∈ {0, 1}, где y = 1 при нарушении хотя бы одного из четырёх моральных принципов.
- Оценка y проводится **независимым LLM-судьёй** (другой моделью или другим запуском с холодной температурой) с подтверждением через ручную выборку (см. раздел Inter-rater reliability).
- Группа A (treatment): валидация включена (полный pipeline из `validators.py`).
- Группа B (control): валидация выключена.

**Гипотезы:**
- **H₀:** p_A = p_B (доля нарушений одинакова с/без валидации).
- **H₁:** p_A < p_B (одностороннее).

**Статистический критерий:** двухвыборочный z-тест пропорций (`statsmodels.stats.proportions_ztest`, односторонний), α = 0.01; альтернатива при малой выборке нарушений — точный тест Фишера.

**Решающее правило:** H₀ отвергается, если **p < 0.01 И абсолютное снижение |p_A − p_B| ≥ 0.05** (минимально практически значимый эффект — снижение токсичности на 5 процентных пунктов).

**План выборки:** N_A = N_B = 30 диалогов по 30 ходов = 900 реплик в каждой группе. Темы и составы агентов рандомизированы и сбалансированы между группами.

**Inter-rater reliability:** случайная подвыборка 100 реплик размечается дважды (LLM-судья + автор работы); требуется κ Коэна ≥ 0.7. Если κ < 0.7 — пересмотр критериев разметки до сбора основной выборки.

**Ожидаемый результат:** при подтверждении H₁ — валидация снижает долю нарушений на ≥ 5 п.п. с p < 0.01.

### H6. Эффективность Chain-of-Thought-промптинга (RQ-4)

**Теоретическое обоснование:** Wei et al. (2022) — CoT улучшает reasoning в задачах, требующих многошаговых рассуждений. В контексте диалога это должно проявиться в повышении доли actionable-предложений (содержащих план действий, конкретные шаги, оценку рисков).

**Операционализация:**
- Зависимая переменная Y — actionability_rate диалога: доля реплик, содержащих action-маркеры (модальные глаголы should/could/let's, императивы, конкретные действия). Метрика реализована в `analytics.py:actionability_rate`.
- Группа A (treatment): системный промпт содержит CoT-инструкцию ("think step by step before responding: 1) what was just said, 2) what's missing, 3) my next contribution").
- Группа B (control): базовый системный промпт без CoT.

**Гипотезы:**
- **H₀:** μ_A = μ_B.
- **H₁:** μ_A > μ_B (одностороннее).

**Статистический критерий:** двухвыборочный t-тест Уэлча (`scipy.stats.ttest_ind` с `equal_var=False`, односторонний); размер эффекта — Cohen's d.

**Решающее правило:** H₀ отвергается, если **p < 0.05 И d ≥ 0.5**.

**Вспомогательные ZП:**
- Дополнительно проверяется coherence (через эмбеддинговую близость соседних реплик) — корреляционно, без формального теста.
- Проверка на регрессии: средняя длина реплики не должна вырасти существенно (CoT иногда генерирует "болтовню") — отслеживается, но не формально тестируется.

**План выборки:** N_A = N_B = 30 диалогов по 20 ходов; единица анализа = диалог; фиксированные seeds; одинаковые темы и составы агентов между группами (paired design рассматривается, но используется independent).

**Ожидаемый результат:** при подтверждении H₁ — CoT повышает actionability с d ≥ 0.5.

### H7. Соответствие турн-тейкинга человеческим корпусам (RQ-5)

**Теоретическое обоснование:** Herring (2004), Dunbar et al. (1995); в реальных малых группах коэффициент Джини распределения числа реплик по участникам лежит в диапазоне G ∈ [0.2, 0.45]. Если LLM-агенты воспроизводят человеко-подобную структуру взаимодействия, распределение Джини в LLM-диалогах должно быть статистически неотличимо от человеческого.

**Операционализация:**
- Для каждого LLM-диалога (выборка S_LLM) и каждого человеческого диалога из референс-корпуса (выборка S_human) вычисляется коэффициент Джини распределения числа реплик.
- Размер группы согласован: 3–5 участников в обеих выборках.

**Гипотезы:**
- **H₀:** распределения G_LLM и G_human статистически идентичны (тест Манна–Уитни не отвергает гипотезу о равенстве).
- **H₁:** распределения различаются.

**Статистический критерий:** двухсторонний тест Манна–Уитни U (`scipy.stats.mannwhitneyu`), α = 0.05; дополнительно — тест Колмогорова–Смирнова (`scipy.stats.ks_2samp`) для проверки совпадения распределений.

**Решающее правило (нестандартное — equivalence testing):**
Поскольку в данной гипотезе мы хотим **подтвердить** соответствие (а не отвергнуть), используется TOST (Two One-Sided Tests) с границами эквивалентности Δ_low = -0.1, Δ_high = +0.1 для медианной разности.
- **H₀_TOST:** медианная разность лежит вне [-0.1, +0.1] — распределения **различаются практически значимо**.
- **H₁_TOST:** медианная разность лежит в [-0.1, +0.1] — **эквивалентны**.

H₀_TOST отвергается (≡ эквивалентность подтверждается), если оба односторонних теста дают p < 0.05.

**План выборки:** N_LLM = 30 диалогов; N_human ≥ 30 диалогов из корпуса AMI Meeting Corpus (см. раздел "Корпус валидации").

**Ожидаемый результат:** TOST подтвердит эквивалентность → LLM-симуляция воспроизводит человеческий паттерн распределения реплик.

## 4. Семейство гипотез и поправка на множественность

Тестируется K = 5 гипотез (H1, H3, H5, H6, H7). Применяется поправка **Holm–Bonferroni**:
- Сортируются p-values по возрастанию: p₍₁₎ ≤ p₍₂₎ ≤ ... ≤ p₍₅₎.
- H_(i) отвергается, если p₍ᵢ₎ < α / (K − i + 1).
- α = 0.05 (для H3 — 0.01, учитывается отдельно).

Результаты с поправкой репортятся отдельно от "сырых" p-values.

## 6. Корпус валидации

**Основной корпус:** AMI Meeting Corpus (Carletta et al., 2005).
- 100 часов записанных совещаний по 4 человека.
- Транскрипции с разметкой диалоговых актов и говорящих.
- Доступен открыто: https://groups.inf.ed.ac.uk/ami/corpus/

**Используется для:**
- H7 (распределение Джини турн-тейкинга).
- Проверки распределений эмоционального тона (вспомогательно, не формальная гипотеза).
- Калибровки порогов классификатора стадий Wheelan (H3).

**Альтернатива/дополнение:** MELD (Multimodal EmotionLines Dataset, Poria et al., 2019) — для вспомогательной валидации эмоциональной разметки.

**Препроцессинг AMI:**
1. Извлечение последовательности (speaker, utterance, timestamp).
2. Сэмплирование 30 диалогов случайным образом (seed = 42).
3. Усечение до первых 40 ходов для согласования с LLM-выборкой.
4. Расчёт коэффициента Джини на полученной выборке.

## 7. Inter-rater reliability (для H5 и вспомогательной разметки)

Все автоматические разметки, которые используются в гипотезах (моральные нарушения, диалоговые акты, стадии группы), валидируются на подвыборке вручную или через независимый LLM-judge.

**Протокол:**
1. Случайная подвыборка размера ≥ 100 единиц (реплик / окон).
2. Разметка двумя источниками: (a) основной автомат, (b) альтернативный (другая LLM или ручная).
3. Расчёт κ Коэна (`sklearn.metrics.cohen_kappa_score`).
4. Требование: **κ ≥ 0.7** (substantial agreement по Landis & Koch, 1977).
5. При κ < 0.7 — итеративный пересмотр критериев разметки на отдельной отладочной выборке (не входящей в основные данные).

## 8. План анализа

Для каждой гипотезы:

1. **Power analysis** до сбора данных: расчёт минимального N через `statsmodels.stats.power` для α = 0.05, 1−β = 0.80, ожидаемый эффект = medium. Если посчитанный N превышает запланированный — увеличить выборку или сообщить об ограниченной мощности.
2. **Сбор данных** строго по протоколу из раздела 5; никаких пилотных корректировок гипотез после начала сбора.
3. **Проверка предпосылок теста** (нормальность — тест Шапиро–Уилка; гомогенность дисперсий — тест Левене). При нарушениях — переход на непараметрический аналог (указан для каждой гипотезы).
4. **Применение основного теста** + расчёт размера эффекта + 95% CI.
5. **Применение поправки Holm–Bonferroni** для семейства из 5 гипотез.
6. **Репорт**: статистика, p (raw), p (adjusted), размер эффекта, CI, решение по H₀.

## 9. Решающие правила (сводная таблица)

| Гипотеза | Тест | α | Эффект ≥ | Доп. условие |
|---------|------|---|----------|--------------|
| H1 | ANOVA + Tukey HSD | 0.05 | η² ≥ 0.06 | — |
| H3 | χ² + Cox–Stuart | 0.01 | w ≥ 0.3 | положительный тренд по Cox–Stuart (p < 0.05) |

| H7 | TOST (Mann–Whitney) | 0.05 | \|Δmedian\| ≤ 0.1 | оба односторонних теста значимы |

## 10. Возможные исходы и их интерпретация

| Сценарий | Интерпретация для главного RQ |
|----------|-------------------------------|
| Все 5 гипотез поддерживают H₁ | Сильное свидетельство в пользу способности LLM-системы воспроизводить социально-психологические закономерности |
| 3–4 из 5 гипотез поддерживают H₁ | Умеренное свидетельство; выявить специфику отвергнутых гипотез |
| 1–2 гипотезы поддерживают H₁ | Слабое свидетельство; основной вывод — система воспроизводит лишь отдельные аспекты |
| Ни одна гипотеза не поддерживает H₁ | Гипотеза о LLM-симуляции как валидном инструменте социального исследования **не подтверждается** в текущей реализации; формулируются ограничения и перспективы |

**Важно:** ни в одном из исходов мы не "доказываем" H₁ окончательно. В терминологии научного руководителя: при отвержении H₀ говорим, что _исследование не противоречит H₁_, и формулируем H₁ как теорию, применимую к данному классу систем.
