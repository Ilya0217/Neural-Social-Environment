# ✅ Проверка гипотез — Turn 5

## 📋 Методология проверки

Проверка гипотез проводится на основе:

1. **Количественные метрики** — значения из научного анализа:
   - Извлечение релевантных метрик (центральность, плотность сети, эмоции, и т.д.)
   - Сравнение с научными порогами и стандартами
   - Вычисление изменений относительно предыдущих метрик

2. **Примеры из диалога** — конкретные сообщения, подтверждающие паттерны:
   - Анализ последних 15-20 сообщений диалога
   - Фильтрация по релевантным признакам (тон, эмоция, содержание)
   - Извлечение цитат с указанием хода, говорящего, адресата

3. **Статистическая оценка** — уровень уверенности:
   - Базовая уверенность от метрик (0.0-1.0)
   - Дополнительные бонусы за наличие примеров (+0.1-0.15)
   - Штрафы за противоречащие данные
   - Финальный статус: confirmed (>0.6), partial (0.3-0.6), rejected (<0.3)
