## Краткое описание проекта

**Цель работы:** Разработка программного комплекса для симуляции многоагентных диалогов с управляемыми стилями общения на основе больших языковых моделей.

**Основные компоненты системы:**

1. **Система управления диалогом** — координация взаимодействия между агентами, выбор следующего говорящего, управление фазами диалога.

2. **Система продвинутых промптов** — формирование контекстно-зависимых инструкций для агентов с использованием техник Chain-of-Thought и Few-shot Learning.

3. **Система валидации** — многоуровневая проверка сообщений (грамматическая, логическая, этическая).

4. **Система аналитики** — расчёт метрик качества диалога и генерация гипотез на основе научных фреймворков.

5. **Веб-интерфейс и CLI** — пользовательские интерфейсы для управления симуляцией и просмотра результатов.

**Технологический стек:**
- Python 3.10+
- OpenAI API / DeepSeek API
- Flask (веб-фреймворк)
- NetworkX (анализ графов)
- Pydantic (валидация данных)
- Matplotlib (визуализация)

**Роли агентов:**
- Explorer (исследователь) — задаёт вопросы, ищет новые идеи
- Critic (критик) — находит риски и проблемы
- Facilitator (фасилитатор) — координирует обсуждение
- Analyst (аналитик) — структурирует информацию
- Innovator (инноватор) — предлагает нестандартные решения

**Научная основа (источники 2010+):**
- Анализ диалоговых актов — ISO 24617-2 (Bunt et al., 2020)
- Модель группового развития — Wheelan (2016, *Creating Effective Teams*, 5th ed.); Bonebright (2010)
- Big Five — Soto & John (2017, BFI-2); язык и личность — Park et al. (2015)
- Размер эффектов — Funder & Ozer (2019); Lakens (2013)
- Inter-rater reliability — McHugh (2012)
- Турн-тейкинг — Levinson & Torreira (2015); Dunbar et al. (2015)
