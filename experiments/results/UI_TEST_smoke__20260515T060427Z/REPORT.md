## 1. Методологическая рамка

Эксперимент реализует **каузальный вывод по Pearl (1995, 2009)** через do-оператор: `P(Y | do(X = x))`, а не `P(Y | X = x)`. Дизайн — **paired counterfactual (within-subject)**: для каждого случайного seed `s ∈ {1..N}` запускаются ДВЕ симуляции, отличающиеся ТОЛЬКО интервенцией:

- **Treatment:** `do(agreeableness[Critic] = 0.90)`
- **Control:**   `do(agreeableness[Critic] = 0.10)`

Поскольку всё остальное (seed, env_context, остальные OCEAN-черты агентов, системные промпты) совпадает, наблюдаемая разница `Δ(s) = Y_T(s) − Y_C(s)` идентифицируется как **Individual Treatment Effect** для seed `s`. Усреднение по парам даёт **Average Treatment Effect (ATE)**.

**Identifying assumptions** (Rubin/Pearl):
- **SUTVA** (no interference): запуски с разными seed независимы.
- **Consistency**: исход `Y(s)` соответствует фактически применённой интервенции (гарантировано детерминированной подменой Big Five до старта диалога).
- **No unmeasured confounders**: все остальные источники вариативности контролируются через фиксированный seed, идентичный env_context и общую LLM.

## 2. Формальная гипотеза

Для каждой outcome-метрики **m** ∈ {avg_tone, avg_reply_length, actionability_rate, reciprocity, emotion_entropy, question_rate}:

- **H₀ᵐ**: `E[Y_T − Y_C] = 0` (интервенция не влияет на m)
- **H₁ᵐ**: `E[Y_T − Y_C] ≠ 0` (интервенция каузально влияет на m)

**Критерий вывода:** H₀ отвергается, если paired t-test даёт `p < 0.05` И `|Cohen's d_z| ≥ 0.3` (оба условия — защита от ложно-значимых эффектов малой практической силы).

## 7. Ограничения и обсуждение

- **Внутренняя валидность:** обеспечена paired-дизайном; вариация между парами устранена внутрисубъектным сравнением (df = N − 1).
- **Статистическая мощность:** при N = 2 мощность для обнаружения малого эффекта (d_z = 0.3) ограничена; рекомендуется N ≥ 30 для надёжной репликации.
- **Внешняя валидность:** результат относится к данной LLM (DeepSeek), данному env_context и данной структуре агентов. Перенос на других LLM требует репликации.
- **Множественные сравнения:** при анализе нескольких метрик одновременно рекомендуется применить поправку Holm–Bonferroni (`statistical_tests.holm_bonferroni`) для контроля FWER.
- **Конструктная валидность:** outcome-метрики операционализированы через agreed-upon формулы из существующей научной базы проекта (см. §5).

## 8. Вклад в научную работу

Данный эксперимент переводит проект из **наблюдательной** парадигмы (корреляции между OCEAN и метриками) в **каузальную** (`P(Y | do(X = x))`). Это:

1. **Удовлетворяет формальному критерию научной гипотезы**: явные H₀/H₁ в нотации математической статистики, парадигма эксперимента (paired RCT-аналог in silico), критерий вывода (p + размер эффекта).
2. **Даёт каузальную интерпретацию**, а не «вайбы»: можно утверждать, что изменение конкретной OCEAN-черты конкретного агента **вызывает** изменение групповой метрики, а не просто коррелирует с ней.
3. **Связано с устоявшимися теориями**: каждая outcome-метрика обоснована published frameworks (Big Five, SNA, ISO 24617-2, Wheelan, Barsade, LIWC, CoT), что обеспечивает теоретическую валидность.
4. **Воспроизводимо**: фиксированные seed, открытый код, JSONL-логи всех диалогов, явный YAML/JSON-конфиг.
